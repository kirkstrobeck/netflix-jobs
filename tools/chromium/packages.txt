# Debian 12 runtime libraries for headless Chromium.
#
# The chromium list is Playwright's own (nativeDeps.ts, debian12-x64 -> reused
# verbatim for debian12-arm64); the font packages are added so text measures the
# same here as it does anywhere else -- Lighthouse's contrast and tap-target
# audits read rendered geometry, so a box that falls back to no font at all is
# not the box a visitor sees.
#

# so transitive libraries (libdrm-common, libsqlite3-0, ...) need no entry here.
